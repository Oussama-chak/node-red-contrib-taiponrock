# node-red-contrib-taiponrock

## Overview
This node forcibly converts all alphabet character strings passed as input
to the character string "Taiponrock".

Even if the input parameter passed is not a character string,
"Taiponrock" is forcibly returned.

In this process, it is a node that changed the sample node that was executing
toLowerCase (a String instance method in JavaScript) to a process that
just returns a constant.

## How to use
Use this node when you want to forcibly convert all passed parameter
strings to "Taiponrock".
